# ASD Explainable GeoAI

This repository contains the processed analytical data and Python code used for the study:

**A Multi-scale Explainable GeoAI Framework for Discovering Spatiotemporal Heterogeneity in Environmental Profiles Associated with Autism Prevalence**

The analysis integrates geospatial analysis, machine learning, explainable artificial intelligence (XAI), and spatial knowledge discovery to investigate spatiotemporal heterogeneity in district-level autism spectrum disorder (ASD) prevalence across New York State from 2010 to 2022.

## Repository structure

```text
ASD-Explainable-GeoAI/
├── README.md
├── code/
│   └── ASD_GeoAI_revision_analysis_2026_v1.ipynb
├── data/
│   ├── autism_fulldata041926.csv
│   └── ASD_GeoAI_data_dictionary.csv
└── results/
    ├── tables/
    └── figures/
```

The `code/` directory contains the complete analysis notebook. The `data/` directory contains the analytical dataset and corresponding data dictionary. The `results/` directory is used for tables and figures generated by the analysis.

## Analysis overview

The workflow includes:

1. Data preprocessing and complete-case selection
2. Descriptive and spatiotemporal analyses
3. Predictor screening using correlation and variance inflation factor assessment
4. Comparison of 12 machine-learning algorithms
5. Hyperparameter optimization and final LightGBM model fitting
6. Global and local SHAP analyses
7. LIME local explanation analysis
8. Dominant-predictor mapping
9. Environmental-signature classification
10. Local Moran's I spatial analysis
11. Temporal, lagged-predictor, and spatial-block sensitivity analyses

The revised primary analysis uses **8,200 complete school-district-year observations** and does not impute missing outcome or predictor values.

## Running the analysis

The main notebook is:

```text
code/ASD_GeoAI_revision_analysis_2026_v1.ipynb
```

The notebook uses repository-relative paths and is designed to be run from the cloned project directory.

The primary analytical dataset is expected at:

```text
data/autism_fulldata041926.csv
```

Output tables and figures are written to:

```text
results/tables/
results/figures/
```

### File paths

The notebook uses relative paths rather than author-specific absolute paths. Users should preserve the repository structure shown above or modify the path configuration near the beginning of the notebook to match their own computing environment.

## Spatial data

Some spatial analyses require the 2020 New York State Unified School District boundary shapefile. These files should be placed in:

```text
data/spatial/tl_2020_36_unsd/
```

Because source geospatial files may not be included in this repository, users should obtain the corresponding public school-district boundary data from the original data provider before running spatial analyses.

## Reproducibility

A fixed random seed of **42** is used where applicable. The same analytical procedures, predictor definitions, model-comparison framework, and explainability methods reported in the manuscript are implemented in the notebook.

The final predictive model is **LightGBM**. XGBoost and the other algorithms remain in the notebook as candidate models evaluated during model comparison.

## Data

The analytical data were compiled from publicly available sources described in the manuscript and Supplemental Materials. The repository provides the processed analytical dataset used for the reported analyses together with a data dictionary describing the included variables.

Users interested in the original source datasets should refer to the manuscript and Supplemental Materials for the corresponding data providers, spatial and temporal resolutions, and preprocessing procedures.
